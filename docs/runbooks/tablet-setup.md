# Tablet setup (Samsung Galaxy, Android)

- Open `https://absurdly-nerdly.github.io/kiddos/` in **Chrome** (not Samsung Internet; storage is per browser), menu → **Install app**. Always launch from that home-screen icon.
- Open the hub once while online, then play one round of each app so it is cached for offline use.
- Speech: Settings → General management → Text-to-speech → install the Google engine's English voice data so numbers are spoken offline.
- Keep her in the app: Samsung pinning (Settings → Security → Pin windows) or Samsung Kids / Google Family Link.
- Never choose "Clear site data" or "Clear storage" for Chrome; it erases progress.
- Backup: hold the corner gear for 3 seconds, answer the question, copy the backup code somewhere private (not this repo). Paste it into the same panel to restore.
- Updates: reopen the app while online; the newest version loads. If it looks stale, use "Check for update" in the parent panel.
